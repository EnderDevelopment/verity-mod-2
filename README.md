# Minecraft Mod: Verity

Verity is a Fabric Minecraft mod for version 1.21.1 that adds a block inspection tool, letting players use the Verity Lens to view a block's registry identifier, hardness, and world position.

## Install

1. Install Minecraft 1.21.1.
2. Install Fabric Loader 0.16.9 or newer.
3. Install Fabric API for Minecraft 1.21.1.
4. Build the project with Java 21:

   ```text
   ./gradlew build
   ```

5. Copy the generated `verity` jar from `build/libs` into the Minecraft `mods` folder.
6. Launch Minecraft using the Fabric profile.

## Use

1. Start Minecraft with the Verity mod installed.
2. Obtain the Verity Lens from the Tools and Utilities creative item group, or run:

   ```text
   /verity give
   ```

3. Hold the Verity Lens.
4. Right-click a block.
5. The mod displays the block's registry identifier, hardness, and position in the world.
